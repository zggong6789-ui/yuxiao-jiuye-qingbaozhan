# 豫校就业情报站 V1.0 运营 SOP

## 最高原则

任何 AI 生成、提取、判断的招聘信息，在正式发布前必须由人工对照官方原文完成最终核验。

第一阶段采用“官方来源发现 → 人工核验 → 标准化入库 → AI 辅助初稿 → 人工终审发布”的流程。AI 负责整理与提效；是否真实、是否有效、是否适合发布，必须由人工确认。

### 收录范围与排除规则

本项目面向本科、硕士、博士三类求职者，不偏向某一个学历层次。重点关注教师、辅导员、行政教辅、实验实训、科研助理、技能人才、高层次人才，以及其他符合项目定位的高校及相关单位正规招聘岗位。

劳务派遣岗位不属于本项目收录范围。发现官方公告明确属于劳务派遣时，在初筛阶段直接排除，不进入正式入库流程；不写入招聘信息表、不做单篇文章、不进入周报，也不作为重点监控岗位。不得因岗位名称、学历要求或其他条件合适而例外收录。

本规则仅排除劳务派遣。合同制、人事代理岗位仍根据官方公告、岗位性质和项目定位逐条判断；如收录，必须按官方原文准确标注，不得包装成事业编。

```text
查来源 → 发现公告 → 核验原文 → 去重 → 写入招聘表
→ 判断内容等级 → AI 生成初稿 → 人工审核 → 发布/进入周报
```

## 1. 每天先检查哪些高校来源

按 `data/高校来源表.csv` 中的“是否重点监控”“建议查看频率”“当前状态”安排。

优先级：

1. 已核验的人事处/人才招聘页面；
2. 近期曾连续发布招聘的学校；
3. 郑州及用户关注度高的学校；
4. 教师、辅导员、行政教辅、实验实训、科研助理、技能人才、高层次人才等岗位栏目；
5. 官方公众号和暂未核验来源，作为补充线索。

每天先检查约 5–8 所重点学校；其余学校按每周 1–2 次轮换检查。

## 2. 如何判断是新公告

先做初筛：如官方公告明确岗位性质为劳务派遣，直接排除，不作为新线索登记，也不进入核验、入库、文章或周报流程。

满足任一条件即可先登记为新线索：

- 公告发布日期晚于上次检查日期；
- 标题、链接或公告编号此前未出现在招聘信息表；
- 是旧公告的补充、延期、岗位调整、考试通知或取消通知；
- 页面显示为新发布，但与已有公告标题高度相似时，先视为“待核验更新”，不要直接重复录入。

## 3. 发现新公告后的核验

至少核验：

- 来源是否为学校官网、人事处、招聘系统或学校官方公众号；
- 原文链接能否正常打开；
- 学校、公告标题、发布日期是否准确；
- 岗位、人数、学历、专业、年龄、党员等条件；
- 报名方式、截止日期或“年度有效”等原始表述；
- 是否有附件、补充公告、岗位表；
- 是否已过期、暂停、取消或进入拟聘公示阶段；
- 编制、备案制、人事代理、合同制等性质是否被官方明确说明。

如岗位性质明确为劳务派遣，停止后续流程并直接排除；不写入招聘信息表。合同制、人事代理不自动排除，仍需按公告原文和项目定位判断。

不明确的信息统一写“公告未明确”，不补猜。

## 4. 什么情况下可以写入招聘信息表

同时满足以下条件才入库：

- 找到可访问的官方原文；
- 关键字段能提取；
- 经人工确认尚未明确失效；
- 与现有记录不是重复公告；
- 能准确保留官方原文链接和核验日期。
- 官方公告未明确其为劳务派遣岗位。

即使暂时不适合公众号单独发布，也可以先入库，发布状态标为“待整理”或“待发布”。

## 5. 如何避免重复录入

录入前依次比对：

- 学校名称；
- 公告标题；
- 官方原文链接；
- 公告发布日期；
- 招聘类型；
- 招聘年份及批次。

同一公告的补充、延期、取消、拟聘等信息，不新建一条普通招聘记录；应更新原记录，并按“后续公告记录规则”保留可追溯信息。

### 后续公告记录规则

补充公告、延期、取消、岗位调整等后续信息，第一阶段可以更新原招聘记录，但必须保留：

- 后续公告标题；
- 后续公告发布日期；
- 后续公告官方链接；
- 具体变更内容。

不得只写一句无法追溯来源的备注。第一阶段可将以上内容完整写入原招聘记录的“备注”字段；每一项均需保留官方链接和日期。

### 招聘信息编号规则

今后的新数据建议使用以下编号规则：

```text
JOB-年份-学校简称-序号
例如：JOB-2026-HNAU-001
```

当前已有 `JOB-001` 暂时保留，不修改；后续统一迁移时再处理。

## 6. 如何判断状态

| 状态 | 判断标准 |
|---|---|
| 当前有效 | 官方公告仍可访问；报名未到截止日，或官方明确写“年度有效”等；未发现终止通知 |
| 即将截止 | 有明确截止日期，且距截止不超过 7 天 |
| 已截止 | 已超过官方明确截止时间 |
| 待核验 | 未找到官方原文、日期不清楚，或发现疑似变更 |
| 已终止 | 官方明确发布取消、暂停、岗位取消或招聘结束通知 |

对于“年度有效”公告，不写“招满为止”；可标为“当前有效（年度有效，具体岗位余缺待确认）”。

## 7. 哪些值得重点解读

适合单篇重点解读：

- 教师、辅导员、行政教辅、实验实训、科研助理、技能人才、高层次人才等核心岗位；
- 招聘人数较多，且官方明确总人数；
- 条件有代表性或容易被误解；
- 有编制、备案制、人事代理等性质被明确说明；
- 待遇、科研启动经费、安家费等信息完整；
- 省内关注度高的学校；
- 政策有新变化，或报名时间临近。

适合进入周报：

- 招聘人数少、条件常规；
- 学院单独招聘；
- 信息不够完整但官方来源明确；
- 已有类似公告刚做过深度解读；
- 补充、延期、资格审查、考试或拟聘通知。

劳务派遣岗位不做重点解读，也不进入周报。合同制、人事代理岗位如符合项目定位，可按官方原文准确标注后，依据本节标准判断内容等级。

## 8. 从发现公告到公众号初稿

1. 检查高校来源表中的重点来源。
2. 发现公告，记录学校、标题、链接、发现日期。
3. 打开原文及附件，先确认是否明确属于劳务派遣；如是，直接排除并结束流程。
4. 人工完成真实性和有效性核验。
5. 在招聘信息表中搜索标题、链接和学校，完成去重。
6. 提取 27 个字段；官方未明确的内容写“公告未明确”。合同制、人事代理等岗位性质按原文填写，不得推断为事业编。
7. 标记当前状态和内容等级。
8. 若适合单篇发布，按 `templates/公众号招聘文章模板.md` 生成初稿。
9. AI 生成后，人工逐段对照原文，特别检查人数、日期、岗位性质、待遇和报名方式。
10. 填写“公众号文章链接”为“未发布”，等待发布。
11. 发布后回填文章链接，并持续监控补充公告。

## 9. AI 与人工的分工

| 事项 | AI 可做 | 人工必须确认 |
|---|---|---|
| 浏览来源表、整理检查清单 | 是 | 否 |
| 长公告提取字段 | 是 | 是 |
| 判断官方来源真实性 | 可辅助 | 是 |
| 判断公告是否仍有效 | 可辅助检索 | 是 |
| 判断是否属于收录范围（特别是劳务派遣） | 可辅助识别原文 | 是 |
| 编制和岗位性质判断 | 仅引用原文 | 是 |
| 去重提示 | 是 | 是 |
| 填写招聘表草稿 | 是 | 是 |
| 生成公众号初稿 | 是 | 是 |
| 解读与发布措辞 | 可起草 | 是 |
| 最终发布 | 否 | 是 |

## 10. 每天 30–60 分钟版本

### 30 分钟基础版

- 10 分钟：检查 5 所重点学校的人事处和招聘页面；
- 5 分钟：登记新线索，排除劳务派遣、明显过期或重复信息；
- 10 分钟：核验 1 条最有价值的公告；
- 5 分钟：写入招聘信息表，或标记为待核验。

### 60 分钟完整版本

- 15 分钟：检查 8–12 所高校来源；
- 10 分钟：登记、初筛劳务派遣、去重、检查补充公告；
- 15 分钟：人工核验 1–2 条公告及附件；
- 10 分钟：整理字段、更新招聘信息表；
- 10 分钟：对 1 条重点公告生成并审核公众号初稿，或汇总为本周周报素材。

每天最重要的产出不一定是发布文章，而是确保新增信息“来源可靠、状态准确、可持续复用”。
