# 公众号招聘文章标准模板

## 标题规则

- 只有官方公告明确写出招聘总人数时，标题才可以使用“招聘 XX 人”。
- 官方未明确招聘总人数时，不得自行汇总、计算或推断人数；标题改用“【学校名称】公开招聘：岗位与报名信息整理”等不含人数的表达。
- 标题不得使用“重磅”“铁饭碗”“有编必冲”等夸张或未经官方确认的表述。

## 标题

### 官方明确招聘总人数时

# 【学校名称】招聘【人数】人：岗位与报名信息整理

### 官方未明确招聘总人数时

# 【学校名称】公开招聘：岗位与报名信息整理

## 导语

【学校名称】发布【公告标题】。本文仅整理官方公告已明确的信息，并将“官方信息”与“豫校就业情报站解读”分开呈现。

## 招聘基本信息

**官方信息**

- 学校名称：【学校名称】
- 公告标题：【公告标题】
- 公告发布日期：【日期】
- 招聘类型：【公开招聘 / 辅导员招聘 / 教师招聘 / 高层次人才招聘】
- 招聘人数：【人数；公告未明确则写“公告未明确”】
- 工作地点：【地点；公告未明确】
- 报名有效期/截止日期：【按官方原文填写；公告未明确】

> 如官方写“招聘信息年度有效”，应原样说明“招聘信息【年份】年度有效，公告未设固定截止日期”，不得改写为“招满为止”。

- 政治面貌要求：【内容；公告未明确】
- 工作经历、学生干部经历、资格证书或科研成果要求：【内容；公告未明确】
- 其他岗位条件：【内容】

- 所属学院或部门：【内容；公告未明确】

## 招聘流程

**官方信息**

公告明确的流程如下：

1. 【报名与资格审查】
2. 【笔试 / 面试 / 试讲 / 考核等】
3. 【体检与考察】
4. 【公示】
5. 【聘用】

如某一环节未说明，写“公告未明确”。

## 编制/岗位性质说明

**官方信息**

- 官方岗位性质表述：【如“专业技术岗”“人事代理人员”等】
- 事业编、备案制、人事代理、合同制等具体性质：【按公告原文填写；公告未明确】
- 薪酬、安家费、科研启动经费等待遇：【按公告原文填写；公告未明确】

> 不得因为公告属于“人才引进”或“公开招聘”，自动表述为“有编制”。

**以下为解读建议，不是学校官方政策。**

- 【报名时最需要重点核对的条件】
- 【公告中容易忽略的材料、专业、年龄或流程要求】
- 【如无固定截止日期，应提醒读者确认具体岗位最新余缺】
- 【其他基于官方信息作出的审慎提醒】

## 报名前提醒

- 请以官方公告及附件为最终依据；
- 重点核对学历、学位、专业、年龄及岗位附加条件；
- 留意补充公告、资格审查、笔试、面试或试讲安排；
- 提交材料前确认文件命名、投递邮箱或报名系统要求；
- 编制、待遇等未明确事项，不作推断；
- 如岗位进展不明，建议向学校或用人学院官方联系人核实。
