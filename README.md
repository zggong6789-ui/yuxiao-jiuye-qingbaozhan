# 豫校就业情报站

豫校就业情报站聚焦河南省高校及相关单位的官方正规招聘信息，为本科、硕士、博士三类求职者提供经过人工核验的招聘整理与解读。

## 重点岗位范围

- 教师
- 辅导员
- 行政教辅
- 实验实训
- 科研助理
- 技能人才
- 高层次人才
- 其他符合项目定位的高校及相关单位正规招聘岗位

## 收录边界与基本原则

- 劳务派遣岗位不属于本项目收录范围：发现后直接排除，不入库、不做单篇文章、不进周报，也不作为重点监控岗位。
- 本规则仅排除劳务派遣；合同制、人事代理岗位仍按官方公告、岗位性质和项目定位逐条判断，并必须如实标注，不得包装为事业编。
- 只以学校、主管部门及相关单位的官方来源作为正式依据。
- 任何 AI 提取、整理或判断的信息，均须由人工对照官方原文完成最终核验后，才能入库或发布。
